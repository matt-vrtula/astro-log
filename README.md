# AstroLog

Vite + Firebase (Hosting + Authentication with Google sign-in).
Live at https://astrolog-2e82d.web.app

## Setup

1. `npm install`
2. `npx firebase login`

The Firebase web config lives in `src/firebase.js` (it is public by design).

## Commands

- `npm run dev` – local dev server (http://localhost:5173)
- `npm run deploy` – build and deploy to Firebase Hosting
